# Regulaminy Hackerspace Szczecin

Dokumenty zostały rozdzielone według przedmiotu regulacji:

1. **[Regulamin Stowarzyszenia Zwykłego](regulamin-stowarzyszenia.md)** — nazwa, cele, członkostwo, władze, zebrania, majątek, utrata członkostwa i pozostałe zasady ustrojowe.
2. **[Regulamin korzystania z przestrzeni](regulamin-przestrzeni.md)** — zasady współżycia, dostęp, bezpieczeństwo, porządek, narzędzia, rezerwacje, wydarzenia, alkohol, monitoring oraz reagowanie na naruszenia w przestrzeni.
3. **[Deklaracja Członkowska](deklaracja-czlonkowska.md)** - Deklaracja Członkowska

W razie sprzeczności pierwszeństwo ma Regulamin Stowarzyszenia Zwykłego.
